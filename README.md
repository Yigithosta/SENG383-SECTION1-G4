# SENG383-SECTION1-G4

**AI-Assisted Child Development Platform** - SENG 383 Software Project III term project (Fall 2026).

A web-based decision support platform where parents and specialists share one schedule, task list and observation record. An AI component summarizes the records for each role; it supports decisions but never makes them.

**Tech stack:** React (Vite), Node.js + Express, SQLite.
